# Синонимы в немецком — Stellas

Разбор синонимов в немецком в сторителлинг-стиле: короткие фразы, диалоги без кавычек, сухие финалы. Дизайн в духе кейса Lendora: тёплый белый фон, двухцветные заголовки, градиенты от лавандового к жёлтому, шрифт Urbanist.

**Сайт:** https://stellasdeutsch-dev.github.io/synonyme/

## Что внутри
- Hero: слово в фразе меняется с эффектом «скрэмбла» и шкалой регистра, телефон с записью экрана, парящие карточки с параллаксом
- Бегущая лента синонимов с цветовой разметкой регистра
- История из комментариев подписчиков + анимированное экзаменационное письмо B1 с правкой от руки
- Цитата, которая «проявляется» по словам при скролле
- Теория: регистр, оттенок, сочетаемость; «дом синонимов» по этажам
- Инфографика: «Анатомия синонима» (кольцевая диаграмма из четырёх слоёв), «Шкала вежливости» для приветствий и прощаний, интерактивная «Карта синонимов»
- Лестница регистров: переключатель и термометр, слова и фраза перестраиваются
- 8 пар-ловушек в слайдере со свайпом: история, правила, примеры с озвучкой, ловушка
- Приём «забыл слово — опиши»: формулы, игра «Спасатель», схема действий
- Тренажёр на 10 ситуаций с графиком результата
- Шпаргалка на 24 группы с поиском и фильтрами
- Платформа Stellas A0–C1: слайд-шоу экранов в ноутбуке, «было / стало» с перетаскиванием, ответы на возражения, калькулятор минут, маршрут A0→C1, записи экрана, отзывы, сравнение цен, тарифы, FAQ

## Стек
Чистые HTML, CSS и JS, без сборки и зависимостей. Mobile-first, `prefers-reduced-motion` учтён. Озвучка — Web Speech API (de-DE).
